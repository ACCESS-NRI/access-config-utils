# YAML and JSON

These are the two parsers that wrap a library and not a grammar: ruamel.yaml for YAML, and the
`json` module of the standard library for JSON. Their configurations are the data of the library
itself. You edit this data directly, and the text is written out again from it. [YAML and
JSON](../user-guide/formats/yaml-json.md) describes how they differ from the other parsers.

# YAML and JSON

The two parsers that wrap a library rather than a grammar: ruamel.yaml for YAML, and the
standard library's `json` for JSON. Their configurations are the library's own data, edited
directly, and written out again from it. [YAML and JSON](../user-guide/formats/yaml-json.md)
describes how they differ from the other parsers.

# Editing

The operations behind a `Config`, the last group before the data the caller sees.
`list_layout` lays out the text of a list whose length changes, `config_insert` adds an entry,
`config_resize` writes a list of another length into its entry, and `config_store` holds the
tree behind one configuration and keeps it in step with the dict.

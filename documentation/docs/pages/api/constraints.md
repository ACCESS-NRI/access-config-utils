# Constraints

These are the ready-made rules for filtering parallelisation layouts. Their base classes,
[`LocalConstraint`][access.config.parallel_component.LocalConstraint] and
[`GroupConstraint`][access.config.parallel_component.GroupConstraint], are documented with the
[components](parallel-components.md). [Constraints](../user-guide/layouts/constraints.md) explains
how to attach them.

::: access.config.parallel_constraints

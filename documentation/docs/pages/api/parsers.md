# Parsers

The base class of the parsers built on a [Lark](https://lark-parser.readthedocs.io/) grammar,
and the parsers of the formats the ACCESS models use. Each module's docstring describes its
format. The pages under *Configuration files* in the [User guide](../user-guide/index.md) show
what each one reads a file as, and [Adding a parser](../developer-guide/adding-a-parser.md)
how a new one is written.

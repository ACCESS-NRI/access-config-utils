# Parsers

Here you find the base class of the parsers that are built on a
[Lark](https://lark-parser.readthedocs.io/) grammar, and the parsers of the formats that the ACCESS
models use. The docstring of each module describes its format. The pages under *Configuration files*
in the [User guide](../user-guide/index.md) show what each parser reads a file as, and [Adding a
parser](../developer-guide/adding-a-parser.md) shows how to write a new one.
